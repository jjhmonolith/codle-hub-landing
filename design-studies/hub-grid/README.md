# 코들 · 짓다 교육 허브 시안

로컬 검토용 정적 페이지. 원본은 별도로 보존했습니다.

공통 제품 비주얼 하나와 각 랜딩으로 이동하는 카드 목록을 구성합니다. 새 서비스는 `catalog.js`의 `landings`에 항목을 추가하면 됩니다. 화면의 번호, 전체 수, 유형별 목록은 자동 반영됩니다. 교과서 카드는 원본의 씨마스와 금성·YBM 목적지를 모두 보존합니다.

기존 프로젝트의 이미지와 폰트만 재사용했습니다. 이미지·영상 생성 및 유료 API 호출은 없습니다. 첫 화면은 CSS 입체 구성과 기존 이미지로 만든 컨셉 시안이며 실제 제품 화면의 정확성을 주장하지 않습니다.

썸네일을 포함한 기존 이미지 일부는 이전 시안에서 생성된 이미지입니다. 실제 랜딩의 스크린샷으로 교체할 수 있습니다.
