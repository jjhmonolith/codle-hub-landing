# 코들 교육 허브 — Studio

2026-09-26 제작. 기존 Cover Flow의 확정된 콘텐츠·직접 탐색 방식·공식 문의폼을 이어받은 별도 랜딩입니다. 기존 시안 폴더는 변경하지 않았습니다.

## 실행

프로젝트 루트에서 `python3 -m http.server 4186 --bind 127.0.0.1` 실행 후:

http://127.0.0.1:4186/prototypes/codle-hub-studio/

정적 HTML/CSS/JavaScript. 폰트와 이미지가 이 폴더에 포함되어 별도 설치 없이 실행됩니다.

## 반영한 결정

- 수업 플랫폼 / 오리지널 콘텐츠 / 코들 × 교과서 / AI 집중캠프 / AI 해커톤, 다섯 상품군.
- 교과서 아래 씨마스 인공지능 기초와 금성·YBM 중/고 정보 교육자료를 구분.
- 금성·YBM 로고는 위아래로 배치하고 문구를 세로 중앙에 정렬.
- 자동 재생 없이 클릭·드래그·스와이프·방향키로 탐색.
- 상품별 직접 문의, 콘텐츠의 Pro 필수 관계, AIDT 출판사 판매 구분.
- 최신 `codle-education-hub/official-inquiry.js`의 문의 구성과 가격 계산 유지. 이전 handoff의 가격 비공개 기록보다 최신 구현을 따랐으며 가격을 새로 만들지 않음.
- 문의폼은 디자인 미리보기. 저장·실제 전송·백엔드 연결 없음.

## 디자인

기존 코들 로고, Pretendard, 흰색·파란색 정체성을 유지. 상단에 다섯 상품 탐색 메뉴를 배치하고 넓은 입체 이미지 쇼룸, 좌측 상품 설명·우측 행동 버튼, 상담 영역, FAQ 순서로 정리했습니다. 작은 노트북 화면에는 낮은 갤러리를 적용합니다. 모바일 메뉴는 가로 탐색, 상품 설명과 교과서 하위 항목은 세로 배치합니다.

`studio.css`가 이 시안의 디자인 규칙을 소유합니다. 기반 스타일은 기존 구현의 폼과 푸터 호환성을 위해 동결 복사했습니다. 일부 이미지에 WebP 최적화를 적용했습니다. 자산 출처는 기존 `../../archive/design-history-2026-09-30/prototypes/codle-education-hub/SOURCES.md`와 관련 generated 폴더 기록을 따릅니다.

## 검증

- 360, 390, 768, 1024, 1440px에서 가로 넘침 없음, 이미지 로딩 실패 없음.
- 키보드 Home/End 탐색, 선택 탭과 상품 패널 동기화.
- 해커톤 문의의 상품 고정, 필수 입력 오류 6개 표시, 유효한 테스트 입력으로 확인 화면 진입.
- 닫기/Escape, 기존 문의 버튼으로 포커스 복원.
- 씨마스 문의 시 해당 이용권만 미리 선택되는 것 확인.
- JavaScript 구문 검사. 시스템 동작 줄이기는 CSS와 기존 갤러리 구현에서 유지.
- 디자인 검사기가 찾은 폼 placeholder와 푸터 대비를 보정.

공개 배포 및 실제 문의 전송은 하지 않았습니다.

## Emil design engineering 적용 — 2026-09-26

`emil-design-eng/SKILL.md`의 입력 빈도·목적에 따른 모션 판단, 직접적인 눌림 반응, 입력 방식별 차등 처리, 충분한 터치 영역을 적용했습니다. `emil.css`가 이번 개선의 스타일을 담당합니다.

| Before | After | Why |
| --- | --- | --- |
| 갤러리 620ms 전환 | 포인터 260ms / 키보드 즉시 | 사용자가 넘기는 속도에 맞춰 응답 |
| 선택 밑줄이 각 탭에서 따로 등장 | 하나의 표시선이 이동 | 선택의 이동 방향을 쉽게 추적 |
| 모든 버튼 동일 정적 상태 | 포인터 눌림 140ms, scale .97 | 클릭이 전달됐다는 즉각적인 피드백 |
| 넘김 38px, 닫기 32px | 각 44px | 손가락과 포인터 조작 여유 |
| 짧은 드래그는 거리만 확인 | 최근 100ms 이동 속도로 flick 감지 | 짧고 빠른 스와이프도 자연스럽게 수용 |
| 전역 hover 스타일 | hover 가능한 fine-pointer 환경에만 적용 | 터치 후 hover 색상이 남는 문제 방지 |
| 문의창 즉시 등장 | 포인터 220ms 진입 / 140ms 종료 | 짧고 목적이 분명한 상태 전환 |
| 키보드에도 모션 | 키보드·Escape·동작 줄이기 즉시 | 입력에 대한 응답 지연 제거 |
| 모바일 인원·일정 나란히 표시 | 세로 배치 | 좁은 입력란과 잘리는 안내문 해소 |

추가 확인: 제스처 계산 7개 assertion, 브라우저 클릭/방향키 전환 시간, 선택 표시선 폭, 문의창 Escape와 포커스 복원, 모바일 44px 닫기·18px 체크박스 및 44px 동의 라벨. 실제 터치 기기는 사용하지 않았으며 모바일 뷰포트와 포인터 드래그로 검수했습니다.
