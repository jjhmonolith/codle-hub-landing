CODLE / MOTION STUDY 01

활동을 바꿔도, 수업은 한곳에서.

활동 선택 → 파이썬 실습 → 퀴즈. 같은 수업 공간에서 배움이 이어집니다.

01 / REST

기본 배열

지금의 3×2 배열. 여섯 카드의 색과 아이콘이 출발점입니다.

02 / PYTHON

파이썬으로 실습

여섯 카드가 수업 활동 목록이 됩니다. 파이썬을 선택하면 문제와 코드·실행 결과가 함께 펼쳐집니다.

03 / QUIZ

퀴즈로 확인

같은 목록에서 퀴즈로 이동합니다. 작업 공간의 틀은 그대로, 코드 대신 질문과 선택지가 나타납니다.

핵심은 ‘같은 수업 안에서 활동 전환’. 선택 강조색과 작업 영역만 바뀝니다. 작은 글자·도구막대·가짜 텍스트 줄은 덜어냈습니다.
구도 확인용 정지 시안이며, 현재 랜딩페이지의 모션은 변경하지 않았습니다.
