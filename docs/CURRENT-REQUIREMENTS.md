# 현재 요구사항과 구현 범위

정리일: 2026-10-01. 기준 작업물: [`prototypes/codle-hub-studio/`](../prototypes/codle-hub-studio/). 기존 기획 원문과 사용자 후속 결정, 2026-09-26 Studio 구현·검증 기록을 함께 읽기 위한 안내입니다. 새로운 요구사항이나 추가 승인을 만들지 않습니다.

## 목표와 대상

교사와 학교·기관의 교육 도입 담당자가 자기 상황에 맞는 AI 교육 상품을 하나라도 발견하고, 상세 확인 또는 적절한 문의 경로로 이어지게 합니다. 코들을 수업 플랫폼뿐 아니라 콘텐츠·교육자료·캠프·해커톤을 제공하는 파트너로 이해하도록 실제 상품을 보여줍니다.

## 현재 상품 구성

| 상위 상품군 | 구성과 행동 | 이용·구매 관계 |
| --- | --- | --- |
| AI 수업 플랫폼, 코들 | 무료 시작·개별 문의 | Basic 무료, Pro 유료 |
| 코들 오리지널 콘텐츠 | 콘텐츠 살펴보기·개별 문의 | 콘텐츠 이용권 이용에는 Pro 라이선스 필요 |
| 코들 × 교과서 | 씨마스 인공지능 기초 / 금성·YBM 중·고 정보 교육자료 | 두 하위 항목의 구매 경로를 구분 |
| 코들 AI 집중캠프 | 프로그램 알아보기·개별 문의 | 학년·인원·일정, 커리큘럼·강사·현장 운영 상담 |
| 짓다 AI 해커톤 | 운영 사례·개별 문의 | AI로 팀의 웹앱 제작·발표, 행사 기획·운영 상담 |

교과서 하위 구성:

- **씨마스 인공지능 기초**: 씨마스 로고와 상품명을 표시. Pro 라이선스가 필요하고 콘텐츠 이용권은 별도. 콘텐츠 체험과 코들 문의로 연결.
- **금성·YBM 중/고 정보 교육자료**: 출판사 로고를 위아래로 쌓고 오른쪽 문구를 세로 중앙에 맞춤. 코들이 개발하고 각 출판사가 판매. 교육자료 체험 및 출판사 구매 안내로 연결하며 코들 직접 견적 문의로 합치지 않음.

이는 초기 여섯 상품 중 씨마스와 AIDT를 한 상위 카드로 묶은 **다섯 상품군**이다. 두 하위 상품의 이용 관계까지 합쳐진 것은 아니다.

## 콘텐츠와 화면

- 주요 문구: “수업부터 해커톤, 캠프까지, 우리 학교에 필요한 AI 교육을 살펴보세요.”
- 상품 이미지 중심의 Cover Flow 쇼룸과 다섯 상품 탐색 메뉴.
- 코들·짓다·출판사 로고, Pretendard, 흰색·파란색 기반 디자인.
- 데스크톱은 상품 설명과 행동 버튼을 좌우로, 모바일은 세로로 배치.
- 상품을 아직 정하지 않은 고객을 위한 일반 상담, Pro 관계·AIDT 구매·캠프와 해커톤 차이 등을 설명하는 FAQ.
- 기관 사례·성과 수치·비교 우위 등을 근거 없이 새로 추가하지 않음. 기존 Claim Ledger의 사실·승인·보류 구분과 이후 결정을 함께 확인.

## 문의 동작

- 상품별 버튼은 해당 문의 항목을 반영한 모달을 연다. 여러 상위 상품을 담는 장바구니·복수 선택 문의 흐름은 사용하지 않는다.
- 일반 상담에서는 코들 구독 / 캠프 / 해커톤 중 상담할 항목을 고른다.
- 구독 문의에는 Pro와 콘텐츠 이용권 선택·참고 요금 계산이 구현되어 있다. 여기서의 이용권 조합은 과거의 여러 상위 상품 동시 문의와 구분한다.
- 문의 대상별 인원·일정 초안은 페이지 메모리에서 보존하며, 입력 오류·내용 확인·수정·닫기 동작을 제공한다.
- **현재는 미리보기**: 저장·백엔드 접수·실제 발송은 없다. 문의 완료로 오해하게 만들지 않는다.
- 코드의 참고 요금은 2026-09-26 이전 구현을 이어받은 값이다. 과거의 가격 비공개 기록과 차이가 있으며, 문서 추가가 실서비스 요금의 재검증·승인을 뜻하지 않는다. 최신 구현은 [`inquiry.js`](../prototypes/codle-hub-studio/inquiry.js)에서 확인한다.

## 인터랙션과 접근성

- 자동 넘김 없이 클릭·드래그·스와이프·방향키·Home/End로 상품 선택.
- 포인터 갤러리 전환 260ms, 선택 밑줄 220ms. 키보드 조작과 시스템 동작 줄이기에서는 즉시 응답.
- 버튼 눌림은 미세한 scale .97 / 140ms 피드백. 호버는 실제 호버 가능한 포인터에서만 적용.
- 넘김·닫기 버튼은 최소 44px 조작 영역.
- 문의창은 포인터 진입 220ms·종료 140ms, 키보드·Escape·동작 줄이기는 즉시 처리.
- 모달 포커스·닫은 뒤 버튼으로 복귀, 모바일 세로 입력란, 글자 대비와 가로 넘침 방지.
- 실제 모바일 기기 검수와 브라우저 모바일 뷰포트 검수는 구분한다. 현재 기록은 브라우저 뷰포트·포인터 검수다.

## 문서 우선순위와 과거 결정

| 과거 문서에서 보이는 내용 | 현재 해석 |
| --- | --- |
| 여섯 상품을 각각 상위 노출 | 교과서 두 종류를 묶은 다섯 상품군 |
| 직접 판매 상품을 담아 한 번에 문의 | 해당 상품별 직접 문의와 일반 상담 |
| 바이브코딩 해커톤 | 현재 화면 명칭은 짓다 AI 해커톤 |
| 장면 필터·대형 선언형 히어로·여러 시안 | 현재 Studio의 상품 이미지 중심 쇼룸 |
| 영상 제작·자동 모션 아이디어 | 보관 이력. 새 영상 제작이나 자동 재생 요구로 해석하지 않음 |
| 옛 시안이 ‘현재·활성’이라는 표현 | 해당 기록 작성 당시의 상태. 현재 작업 위치는 Studio |

작업 시 이 문서와 [현재 구현 기록](../prototypes/codle-hub-studio/README.md)을 먼저 확인하고, [인수인계](../SESSION-HANDOFF.md)와 [원래 결정 이력](../discovery-pack/00-charter/decision-log.md)으로 근거를 추적한다. 기존 원문은 이력 보존을 위해 함께 저장한다. 충돌하는 오래된 지침을 현재 코드로 자동 복원하지 않는다.

## 구현·운영 범위

정적 HTML/CSS/JavaScript이며 필수 이미지·폰트는 Studio 안에 포함되어 있다. GitHub 저장소는 공개 상태이고, 공개 웹사이트 배포·문의 백엔드·실제 개인정보 수집은 아직 구현 범위에 포함되지 않는다. 예전 디자인 보관함과 설치한 스킬은 로컬에 남아 있다.
