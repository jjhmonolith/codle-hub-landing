## 새 허브의 노출 구조

이 허브의 1차 목적은 기존 고객이 코들의 제공 범위를 새로 발견하여 **“이런 것도 하네? 남은 예산으로 이걸 도입하자”**고 생각하게 만드는 것이다. 따라서 내부 상품 hierarchy나 구매 결합 규칙을 첫 화면의 노출 hierarchy로 사용하지 않는다.

아래 6개 제공물은 어느 하나의 하위 메뉴에 숨기지 않고 허브 최상위에서 각각 발견 가능해야 한다.

```text
Codle 상품 허브
├─ 코들 라이선스
├─ 코들 오리지널 콘텐츠
├─ 씨마스 인공지능 기초
├─ AIDT 교육자료
├─ AI 집중캠프
└─ 바이브코딩 해커톤 대회
```

상품 내부의 상하위 관계는 해당 상품을 선택한 뒤 설명한다.

```text
코들 라이선스
├─ Basic — 무료 티어
└─ Pro — 유료 티어

코들 오리지널 콘텐츠
├─ 코들 AI 콘텐츠 이용권
└─ 코들 Pro 콘텐츠 — 같은 영역에서 설명·전시 예정
```

## 구매 구조

노출 구조와 별개로 실제 구매·이용 관계는 별도의 `이용 구성` 또는 견적 단계에서 설명한다.

```text
플랫폼 이용: Basic 또는 Pro
콘텐츠 이용: Pro + 오리지널 콘텐츠 이용권 / Pro + 씨마스 인공지능 기초 이용권
프로그램 도입: AIDT 교육자료 / AI 집중캠프 / 바이브코딩 해커톤 대회
해커톤 하위 구성: 짓다 플랫폼
```

콘텐츠 이용권만 단독 구매할 수 없으며 Pro 라이선스가 필수다. 가격·최소수량·계약기간과 두 콘텐츠 이용권의 동시 구매 조건은 아직 단정하지 않는다.

## 분류 원칙

1. Basic과 Pro는 독립 상품 카드가 아니라 `코들 라이선스`의 하위 티어다.
2. 기존 코드의 `Codle AI` 콘텐츠 이용권은 새 허브에서 `코들 오리지널 콘텐츠` 상품군으로 설명한다.
3. 코들 Pro 콘텐츠는 오리지널 콘텐츠 영역에서 함께 설명·전시한다. 다만 라이선스 포함 관계와 별도 과금 관계는 아직 확정하지 않는다.
4. 씨마스 인공지능 기초는 코들 오리지널 콘텐츠와 구분되는 제휴 콘텐츠 상품이다.
5. AIDT 교육자료는 별도 기관형 콘텐츠 상품군으로 둔다. YBM 중·고등 정보 AI 디지털 교육자료라는 과거 파트너 요청 자산이 관찰됐지만 현재 공식명·판매 상태는 추가 확인한다.
6. AI 집중캠프와 바이브코딩 해커톤 대회는 서로 다른 최상위 상품으로 반드시 분리한다.
7. 짓다 플랫폼은 독립 최상위 상품이 아니라 바이브코딩 해커톤의 하위 구성으로 둔다.
8. 교사 연수, 학생 사전교육·체험, K-12 풀 운영 대행, 시상·간식·식사 옵션은 독립 상품으로 세지 않는다. 필요하면 각 프로그램의 제공 범위 또는 운영 옵션으로 설명한다.

## 아직 확정하지 않는 것

- 허브의 카드 수와 섹션 배치
- 가격 숫자와 할인 규칙
- Pro와 콘텐츠 이용권의 가격·최소수량·계약기간·동시 구매 조건
- 캠프와 해커톤 각각의 세부 패키지 범위
- 상품별 CTA와 목적지
- 수치·사례·인증 문구
