# Codle New Landing Discovery Pack

이 디렉터리는 기존 Source Pack과 독립적인 새 랜딩의 정본이다.

## 구조

- `00-charter/`: 목적, 범위, 결정 기록
- `01-evidence/`: 상품 인벤토리, Claim Ledger, 원천 receipt
- `02-research/`: 인터뷰·카드소팅·트리테스트와 관찰
- `03-strategy/`: 검증된 구매그룹/JTBD, 메시지 원칙, Page Contract
- `04-design-contract/`: 레퍼런스 분석, 디자인 시스템, AI 생성 계약
- `05-validation/`: 사용성·접근성·성능·시각·출시 검증

## 사용 규칙

1. 기존 Source Pack은 `reference only`다.
2. 새 1차 원천 receipt와 owner 승인이 없는 claim은 `pending`이다.
3. AI와 사용자 화면에는 `approved` claim만 전달한다.
4. 관찰과 해석을 분리한다.
5. 화면 설계는 Gate 0과 구매그룹 연구 전에는 시작하지 않는다.
