## 문의 폼 계약

### 상품 선택

- 코들 라이선스
- 코들 오리지널 콘텐츠
- 씨마스 인공지능 기초
- AI 집중캠프
- 바이브코딩 해커톤

AIDT는 체크박스에 넣지 않는다.

### 필드

| 필드 | 필수 여부 | 목적 |
|---|---|---|
| 기관명 | 필수 | 기관 맥락 확인 |
| 담당자 역할 | 선택 | 내부 구매 역할 파악 |
| 검토 상품 | 필수·복수 | cross-sell 문의 routing |
| 예상 대상/인원 | 선택 | 견적 범위 파악 |
| 희망 시기 | 선택 | 운영 가능성 확인 |
| 예산 사업명/출처 | 선택 | 실제 budget trigger 학습 |
| 요청 내용 | 선택 | 자유 요구 수집 |
| 연락처 | 필수 | 응대 |
| 개인정보 동의 | 필수 | 제출 근거 |

### 상태

- default
- focus
- validation error + 해당 필드로 초점 이동
- submitting + 중복 제출 방지
- success + 접수 다음 단계 안내
- server error + 입력값 보존·재시도

## 분석 이벤트

PII를 브라우저 analytics로 보내지 않는다.

- `hub_offering_view`
- `hub_offering_select`
- `hub_situation_filter`
- `hub_comparison_view`
- `hub_aidt_guidance_view`
- `hub_inquiry_open`
- `hub_inquiry_submit_attempt`
- `hub_inquiry_submit_result`

상품 ID, 위치, 세션 내 선택 수, 결과 상태만 전송한다. 제출 후 CRM 연결은 서버 발급 비식별 lead ID를 사용한다.

## 공개 전 blocker

1. 실제 공개 문의 폼 URL 또는 내장 폼 endpoint
2. AIDT 출판사별 최신 안내 URL — 없으면 정보만 제공하고 링크 없음
3. P-001~P-003 설명 카피 owner 승인
4. 개인정보 처리 문구·동의 링크
5. 폼 성공/오류/중복 제출 실제 검증
