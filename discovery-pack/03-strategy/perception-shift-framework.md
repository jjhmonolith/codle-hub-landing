# Codle 고객 인식 전환 프레임워크 v1

- 상태: 전략 원칙 승인
- 원천: R-011
- 목적: 구체 IA·카피·디자인 전에 모든 후속 의사결정이 같은 인식 전환을 만드는지 판단

## 1. 전환 목표

```text
현재 인식
코들 = 수업에 사용하는 소프트웨어

목표 인식
코들 = AI 교육의 전 범위를 설계·제공·운영하는 파트너
```

단순히 `상품이 많다`고 알리는 것이 아니다. 코들이 AI 교육의 여러 층위를 실제 상품으로 연결해 제공한다는 점을 고객이 이해하게 만드는 것이 목표다.

## 2. 범위를 증명하는 상품 역할

| 제공 범위 | 대표 상품 | 고객이 새로 이해해야 할 것 |
|---|---|---|
| 교육 인프라·수업 운영 | 코들 라이선스 Basic/Pro | 코들은 교실에서 사용하는 플랫폼을 제공한다. |
| 자체 교육 콘텐츠 | 코들 오리지널 콘텐츠·Pro 콘텐츠 | 코들은 플랫폼만이 아니라 수업 내용을 직접 제공한다. |
| 교과서·파트너 연계 | 씨마스 인공지능 기초 | 코들은 교과 진도와 연결된 제휴 콘텐츠도 제공한다. |
| 교과 디지털 교육자료 | AIDT 교육자료 | 코들은 출판사·교과 단위의 디지털 수업자료도 다룬다. |
| 기관 교육 프로그램 | AI 집중캠프 | 코들은 단기 교육 프로그램을 설계·운영한다. |
| 대회·성과 운영 | 바이브코딩 해커톤 대회 | 코들은 교육청·학교 단위 행사와 결과물까지 운영한다. |

이 표는 인식 전환을 위한 전략 지도이며, 최종 화면의 카드 순서나 섹션 구조가 아니다.

## 3. 인식 전환 과정

```text
인지 확장
“코들이 이런 것도 하네”
        ↓
자기 상황 연결
“우리 학교/교육청의 이번 사업에 맞겠다”
        ↓
집행 가능성 판단
“대상·기간·예산·운영 방식이 가능하겠다”
        ↓
내부 공유
“이 자료로 담당자·관리자에게 제안할 수 있겠다”
        ↓
교차판매 행동
자료 요청 / 견적 문의 / 도입 상담
```

## 4. 페이지가 반드시 답해야 할 질문

각 주요 상품은 고객에게 다음을 이해시켜야 한다.

1. 코들이 이 상품까지 제공한다는 사실
2. 어떤 학교·기관·사업 상황에 맞는지
3. 올해 또는 남은 예산으로 집행 가능한 종류인지
4. 무엇을 제공하고 기관이 무엇을 준비해야 하는지
5. 기간·대상·규모·가격이 어떤 변수로 결정되는지
6. 내부 검토를 위해 무엇을 공유할 수 있는지
7. 다음 문의 후 어떤 절차가 이어지는지

## 5. 노출 원칙

- 라이선스는 중요한 상품이지만 전체 허브의 상위 개념으로 사용하지 않는다.
- 오리지널·씨마스·AIDT·캠프·해커톤을 라이선스 아래에 숨기지 않는다.
- 각 상품은 최상위 발견 단위로 존재해야 한다.
- 복잡한 라이선스+콘텐츠 구매 조합은 발견 이후에 설명한다.
- 상품 간 우열보다 AI 교육 범위의 확장을 보여준다.
- `모든 것을 제공한다`는 추상 주장보다 실제 상품·사례·운영 범위로 증명한다.

## 6. 검증 방법

### 노출 전 질문

- 코들은 무엇을 하는 회사/서비스라고 생각하는가?
- 코들에서 구매할 수 있다고 아는 것은 무엇인가?

### 프로토타입 사용 후 질문

- 코들이 제공하는 것을 기억나는 대로 말해 달라.
- 처음 알게 된 상품은 무엇인가?
- 현재 기관 예산으로 검토해볼 상품은 무엇인가?
- 관리자 또는 담당자에게 전달하려면 어떤 정보가 더 필요한가?

### 1차 통과 기준

- 참여자가 소프트웨어 외 3개 이상의 제공 범주를 비보조 회상한다.
- 참여자의 80% 이상이 처음 알게 된 상품을 하나 이상 말한다.
- 참여자의 60% 이상이 자신의 예산·사업 상황과 상품 하나를 연결한다.
- 씨마스·AIDT·캠프·해커톤이 라이선스의 부속 기능이라고 오해하는 사례가 없다.

수치는 초기 검증 기준이며 실제 표본과 조사 조건을 기록해 해석한다.

## 7. 측정 방향

- 비라이선스 상품 발견률
- 세션당 서로 다른 상품군 탐색 수
- 기존 고객의 신규 상품 상세 진입률
- 예산·운영·사례 자료 열람률
- 비라이선스 상품 자료 요청·문의율
- CRM의 기존 고객 교차판매 기회 생성률

최종 판단은 페이지 클릭이 아니라 `새 상품 발견 → 내부 검토 → 유효 문의 → 교차판매 기회`의 연결로 한다.
