# 메시지 원칙 v1

- 작성일: 2026-08-24
- 상태: R-016 owner 승인 반영
- 적용 범위: 허브 IA, 저충실도 프로토타입, 향후 카피 초안
- 금지: pending/prohibited claim을 카피 생성 문맥에 포함

## 1. 메시지의 역할

허브는 `코들 = 소프트웨어`라는 기존 인식에 논쟁하지 않는다. 여섯 상품을 같은 최상위 탐색 층위에서 보여주어 고객이 코들의 실제 제공 범위를 스스로 확장해 이해하게 한다.

내부 전략 문장 `AI 교육의 전 범위`는 대외 절대 claim으로 그대로 쓰지 않는다. 범위는 추상 문장이 아니라 상품 목록으로 증명한다.

## 2. 핵심 메시지 순서

```text
1. 코들에 여섯 종류의 상품이 있다는 사실
2. 각 상품이 맞는 수업·사업·운영 상황
3. 콘텐츠·AIDT의 특수 구매 관계
4. 캠프와 해커톤의 결과물 차이
5. 내부 검토용 견적 또는 출판사 안내
```

## 3. 상품 label

최상위 label은 아래 정본 명칭만 사용한다.

1. 코들 라이선스
2. 코들 오리지널 콘텐츠
3. 씨마스 인공지능 기초
4. AIDT 교육자료
5. AI 집중캠프
6. 바이브코딩 해커톤

공개 최상위 label에서 사용하지 않을 말:

- 모델
- 플랜
- 구독권
- 번개
- 디지털 새싹형
- 찾아가는 AI 체험학교 패키지
- AI 플랜

## 4. 카드 메시지 계약

모든 상품 카드는 같은 구조를 갖는다.

```text
상품명
역할/상황 한 줄
고객이 얻는 활동·산출물
구매 관계 badge
다음 행동
```

단, CTA는 동일하지 않다.

- 직접 판매 5개: `내부 검토용 견적 문의` 또는 통합 문의에서 선택
- AIDT: `출판사 안내` 자리. 실제 최신 URL을 확보하기 전 클릭 가능한 외부 링크를 만들지 않음

## 5. 콘텐츠 표현

- 오리지널 콘텐츠와 씨마스는 라이선스 아래에 숨기지 않는다.
- 두 상품은 각각 최상위 카드로 발견시킨다.
- 구매 구성에서 `Pro 라이선스 필수`를 반드시 설명한다(C-018, C-019, C-032).
- 두 이용권의 동시 구매를 운영 준비 전까지 적극 홍보하지 않는다.
- 코들 Pro 콘텐츠의 확정 목록이 없으므로 별도 상품처럼 설명하지 않는다.

## 6. AIDT 표현

허용 문구:

> 코들이 만들고 각 출판사가 판매합니다.

규칙:

- 코들 견적 CTA 금지
- 코들이 학교에 판매·수납하는 인상 금지
- 장기 상시 제공을 암시하는 표현 금지
- 출판사별 최신 상품명·안내 URL 미확정 상태를 링크로 위장하지 않음
- 출판사 로고·교재 이미지 권리 승인 전 미사용

## 7. 캠프·해커톤 표현

허용 구분:

- AI 집중캠프: `AI를 배우고 직접 만들어보는 집중 교육 운영`
- 바이브코딩 해커톤: `문제를 정하고 팀 결과물을 완성·발표하는 프로젝트형 행사 운영`

금지·주의:

- 학교형/교육청형을 공식 패키지명처럼 사용하지 않음
- 해커톤에 심사·시상·생기부가 항상 포함된다고 쓰지 않음
- 캠프와 해커톤을 한 상품의 옵션처럼 보이게 하지 않음
- 짓다를 독립 최상위 상품으로 만들지 않되, 해커톤 하위 플랫폼/브랜드 단서로 유지

## 8. 가격·사례·증거

- 가격 숫자와 할인율 미노출(C-030)
- 개별 견적과 내부 매출·이익률 미노출
- 기관명·로고·사진·성과 수치 미노출(C-031)
- 사례가 필요하면 `중학교`, `교육청` 등 익명 정성 맥락만 사용
- `국내 1위`, 학교 수, 도입률, 만족도 등 pending claim 사용 금지

## 9. CTA 원칙

주 CTA는 즉시 결제가 아니라 내부 의사결정을 지원해야 한다.

- 직접 판매 5개: `내부 검토용 견적 문의`(C-025)
- 복수 상품 동시 선택 가능(C-029)
- 예산 사업명/출처는 선택 입력
- AIDT는 출판사 안내로 분리(C-033)
- 공개 폼 URL이 확인되기 전 실제 링크를 생성하지 않음

## 10. 향후 카피 QA

모든 공개 문장에 대해 확인한다.

- 승인된 claim ID가 있는가?
- 가격·수치·기관명·권리 미확정 자산이 섞이지 않았는가?
- 콘텐츠 단독 구매 가능으로 읽히지 않는가?
- AIDT를 코들 직접 판매로 읽히게 하지 않는가?
- 캠프와 해커톤이 활동·산출물로 구분되는가?
- `모든`, `전부`, `완벽`, `유일`, `1위` 같은 절대 표현이 없는가?
