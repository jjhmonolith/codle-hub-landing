## 1. 이번 조사에서 결정할 것

1. 기존 고객이 현재 코들을 어떤 범위의 공급자로 인식하는가.
2. 여섯 최상위 상품 중 무엇을 처음 발견하고, 무엇을 기존 인식과 혼동하는가.
3. 상품별 실제 구매 시작 계기·예산/사업 상황·시기를 무엇이라 부르는가.
4. 누가 제안·검토·승인·계약/행정·운영하는가.
5. 내부 공유와 승인에 필요한 정보·문서·증거가 무엇인가.
6. Pro 필수 콘텐츠와 AIDT 출판사 판매 구조를 어느 단계에서 어떻게 설명해야 오해가 없는가.
7. 허브에서 Team Monolith/Codle 문의와 출판사 구매 경로를 어떻게 구분해야 하는가.

## 2. 핵심 가설과 반증 조건

| 가설 | 반증 신호 | 필요한 결정 |
|---|---|---|
| 기존 고객은 코들을 주로 수업 소프트웨어로 인식한다 | 비라이선스 상품을 이미 여러 개 자발적으로 회상 | 인식 전환보다 비교·선택 지원 비중 확대 |
| 모든 주요 상품의 최상위 노출이 새로운 교차판매 발견을 만든다 | 카드가 많아져 핵심 상품을 찾지 못하거나 서로 같은 상품으로 오해 | 노출 단위는 유지하되 진입 구조·분류 vocabulary 재설계 |
| 기존 고객은 남은 예산/신규 사업 상황에 인접 상품을 연결한다 | 실제 구매가 연간 본예산·조달 일정에만 의해 결정 | `남은 예산` 메시지 축소, 시기별 구매 지원 강화 |
| 교사가 내부 champion 역할을 한다 | 행정실·부장·교육청·출판사가 먼저 안건을 만들고 교사는 운영만 담당 | 역할별 진입·공유 자료 구조 재설계 |
| AIDT는 다른 상품과 같은 코들 견적 CTA를 쓰면 혼동된다 | 고객이 출판사 구매를 자연스럽게 알고 코들 문의를 원하지 않음 | 출판사별 구매 경로를 명시적으로 분리 |

가설은 인터뷰 결과가 아니다. 관찰 사실과 해석을 노트에서 분리한다.

## 3. 1차 표본: 14명

한 기관 안에서 제안자와 승인자/행정 담당자를 함께 모집할 수 있으면 2~3개 의사결정 체인을 우선 확보한다.

| 코호트 | 목표 인원 | 우선 역할 | 반드시 포함할 최근 경험 |
|---|---:|---|---|
| 코들 라이선스만 이용 중인 기존 고객 | 3 | 정보/AI 교사, 부장 | 최근 12개월 내 갱신·확대·추가 예산 검토 |
| 콘텐츠 구매 또는 검토 경험 고객 | 2 | 수업 담당 교사, 콘텐츠 선정자 | 오리지널 또는 씨마스 구매/검토 |
| 캠프·해커톤 제안·운영 경험 학교 | 2 | 제안 교사, 운영 책임자 | 실제 안건 제안·견적·행사 운영 |
| 학교 승인·계약/행정 역할 | 2 | 부장, 관리자, 행정실/계약 담당 | 최근 에듀테크 또는 프로그램 계약 처리 |
| 교육청/교육지원청 사업 역할 | 2 | 장학사, 사업 담당, 계약 협력자 | 학교 단위가 아닌 사업 기획·집행 |
| AIDT 출판사 판매 경로 | 2 | 출판사 PM/영업/파트너 담당 | 고객 판매·수납·코들 정산 흐름 |
| 검토 후 보류·이탈한 고객 | 1 | 최초 제안자 또는 승인자 | 최근 실제 보류 이유와 필요한 증거 |

예비 표본 6명을 별도 모집해 노쇼와 역할 편중을 보완한다. 동일 조직·동일 직무의 반복으로 새 정보가 나오지 않으면 남은 좌석을 반대 역할 또는 보류 고객으로 전환한다.

## 4. 모집 우선순위

1. 기존 코들 고객 중 라이선스 외 상품을 구매하지 않은 학교
2. 같은 학교 안의 제안자–승인자/행정 담당자 쌍
3. 콘텐츠, 캠프, 해커톤 중 하나를 실제 구매했거나 보류한 고객
4. 교육청 사업 담당자
5. AIDT 출판사 판매·정산 담당자

성공 고객만 모집하지 않는다. 보류·축소·반대 경험을 의도적으로 포함한다.

## 5. 조사 방식

- 형식: 1:1 반구조화 인터뷰 45분
- 보조 방식: 최근 실제 안건의 문서·메신저·견적·품의 항목 회상 또는 화면 공유
- 개념 검증: 시각 디자인 없는 여섯 상품명/짧은 사실 카드로 분류·선택 과제
- 기록: 동의 시 녹음, 아니면 실시간 노트
- 산출 단위: 사람별 사실 노트 + 역할별 패턴 + 상품별 구매 trigger + 승인 증거 목록

## 6. 인터뷰 전 준비

- [ ] 참여자의 역할과 최근 구매/보류 사건 확인
- [ ] 기존 코들 이용 범위 확인(라이선스/콘텐츠/프로그램)
- [ ] 녹음·문서 캡처 동의 범위 확인
- [ ] 승인된 claim만 포함한 중립 상품 카드 준비
- [ ] 가격·성과·권리 pending 정보가 카드에 들어가지 않았는지 점검
- [ ] AIDT 카드는 `출판사 판매`와 `코들 직접 판매 아님`을 사실 확인 과제로 분리

## 8. 1차 종료·통과 기준

- 각 핵심 역할군에서 최소 2건 이상의 최근 실제 사건을 확보한다. 단, 보류 고객은 최소 1건으로 시작한다.
- 제안→승인→계약/지불→운영의 역할 지도를 2개 이상 실제 기관 체인으로 재구성한다.
- 상품별 구매 trigger는 최소 2개 독립 원천에서 반복될 때만 패턴으로 승격한다.
- 소프트웨어 외 3개 이상 범주 비보조 회상, 신규 상품 발견, 실제 사업 연결 여부를 참여자별로 기록한다.
- AIDT를 코들 직접 견적으로 오해하거나 콘텐츠를 Pro 없이 단독 구매 가능하다고 오해한 지점을 기록한다.

초기 수치 기준은 방향성 신호이며 모집 편향·표본 맥락과 함께 해석한다.

## 10. 리서치 완료 전 금지

- 인터뷰 가설을 공개 카피의 사실처럼 쓰지 않는다.
- 한 학교·한 교육청 사례를 전체 시장 규칙으로 일반화하지 않는다.
- 미승인 가격·성과·권리·출판사 URL을 노출하지 않는다.
- 카드 정렬 결과 전에 최종 내비게이션·카드 순서를 확정하지 않는다.
