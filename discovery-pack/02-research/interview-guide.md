# 구매그룹 인터뷰 가이드 v1

- 권장 시간: 45분
- 원칙: 의견보다 최근 실제 사건을 먼저 묻는다.
- 진행 규칙: 상품 목록은 baseline 질문이 끝난 뒤에만 보여준다.

## 0. 시작·동의 — 3분

- 오늘은 제품 평가가 아니라 최근 기관 구매/도입 과정과 필요한 정보를 이해하려는 인터뷰라고 설명한다.
- 녹음, 익명화, 문서/화면 캡처의 허용 범위를 각각 확인한다.
- 정답이 없고 보류·반대 경험도 중요하다고 안내한다.

## 1. 역할과 최근 사건 — 7분

1. 현재 역할과 담당 업무를 설명해 달라.
2. 최근 12개월 안에 교육 소프트웨어·콘텐츠·캠프·대회를 검토하거나 구매한 가장 최근 사건은 무엇인가?
3. 그 일은 누가, 어떤 계기로 처음 꺼냈는가?
4. 본인은 어느 단계에서 무엇을 했는가?

추적 질문:
- 기억나는 실제 문서·메신저·회의·일정을 기준으로 말해 달라.
- 일반적으로 그렇다는 설명과 이번 사건에서 실제로 있었던 일을 구분해 달라.

## 2. 노출 전 인식 — 5분

1. 지금까지 코들을 어떤 회사 또는 서비스라고 생각했는가?
2. 코들에서 구매하거나 제공받을 수 있다고 아는 것을 모두 말해 달라.
3. 코들 외 공급자를 찾게 되는 교육 업무는 무엇인가?

진행자는 이 단계에서 여섯 상품명을 먼저 말하지 않는다.

## 3. 구매 계기·예산·시기 — 8분

1. 최근 사건의 예산 또는 사업은 내부에서 정확히 무엇이라고 불렀는가?
2. 예산이 생긴 시점과 실제 계약해야 했던 시점은 언제였는가?
3. 처음 계획한 예산인가, 남은 예산인가, 다른 항목에서 조정한 예산인가?
4. 금액 외에 계약을 결정한 변수는 무엇이었는가?
5. 진행을 늦추거나 포기하게 만든 조건은 무엇이었는가?

주의:
- 예산 항목명을 유도하지 않는다.
- `남은 예산`을 전제로 묻지 않는다.
- 정확하지 않은 수치는 추정치로 별도 표시한다.

## 4. 구매그룹과 내부 승인 — 8분

최근 사건 기준으로 다음 역할을 한 사람을 각각 확인한다.

- 문제 또는 기회를 처음 제기한 사람
- 상품을 찾고 비교한 사람
- 수업/행사를 실제 운영할 사람
- 예산을 승인한 사람
- 계약·품의·조달을 처리한 사람
- 반대하거나 보류시킨 사람
- 외부 공급자와 최종 소통한 사람

질문:
1. 다음 사람에게 넘기기 위해 어떤 자료가 필요했는가?
2. 실제로 공유한 파일·링크·견적·사례가 있었는가?
3. 부족해서 직접 다시 만든 자료는 무엇인가?
4. 최종 승인 직전 가장 많이 받은 질문은 무엇인가?

## 5. 중립 상품 카드 과제 — 8분

시각 디자인 없이 승인된 사실만 담은 여섯 카드를 한 번에 보여준다.

- 코들 라이선스
- 코들 오리지널 콘텐츠
- 씨마스 인공지능 기초
- AIDT 교육자료
- AI 집중캠프
- 바이브코딩 해커톤

과제:
1. 처음 알게 된 상품을 골라 달라.
2. 서로 같은 종류라고 생각한 것과 다른 종류라고 생각한 것을 묶어 달라.
3. 현재 기관 상황과 연결되는 상품 하나를 고르고 이유를 말해 달라.
4. 관리자나 담당자에게 전달할 상품 하나를 고르고, 전달 전에 필요한 정보를 말해 달라.
5. 어느 상품이 다른 상품에 포함된다고 이해했는지 설명해 달라.

진행자는 정답을 먼저 설명하지 않고 오해 경로를 기록한다.

## 6. 판매 경로 이해 확인 — 4분

카드 과제 후 승인된 상업 관계를 짧게 제시하고 이해를 확인한다.

- 오리지널·씨마스 콘텐츠 이용권은 Pro 라이선스가 필수다.
- AIDT 교육자료는 출판사가 판매·수납하고 이후 코들에 정산한다.
- 나머지 다섯 최상위 상품은 Team Monolith/Codle이 직접 판매한다.

질문:
1. 예상과 달랐던 관계는 무엇인가?
2. 어느 시점에 이 설명이 나와야 하는가?
3. AIDT를 검토한다면 코들 문의와 출판사 구매 중 어떤 경로를 기대하는가?
4. 경로를 잘못 이해하지 않으려면 어떤 표기나 자료가 필요한가?

## 7. 마무리 — 2분

1. 코들이 제공한다고 새로 이해한 것은 무엇인가?
2. 실제로 다음 검토를 한다면 누구와 무엇을 공유하겠는가?
3. 우리가 꼭 인터뷰해야 할 다른 역할은 누구인가?

## 진행자 기록 체크리스트

- [ ] baseline에서 비보조 회상한 상품/범주
- [ ] 처음 발견한 상품
- [ ] 실제 기관 상황과 연결한 상품
- [ ] 제안→영향→승인→계약/지불→운영 역할
- [ ] 정확한 예산/사업명과 시기
- [ ] 실제 반대·보류 이유
- [ ] 내부 공유에 필요했던 자료
- [ ] Pro 필수 관계 오해 여부
- [ ] AIDT 판매 경로 오해 여부
- [ ] 직접 인용과 진행자 해석 분리
- [ ] 후속 증거 요청과 사용 동의 범위
