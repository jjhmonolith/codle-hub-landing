  - `not-applicable`: 해당 상품에 그 질문이 성립하지 않음

### 판정 근거 요약

- **P-001 Q7 = conflicting.** 가격 페이지·문의 폼은 Pro 1인 기준가를 22,000원으로 표기하는데 `[source: S-017 / E-022]`, 같은 기간 실제 세금계산서 발행 단가는 10,000원·13,000원이 흔하다 `[source: S-062 / E-071]`. 정가와 실판매가가 상시 괴리된다. 허브에 가격을 노출할 때 어느 쪽이 사실인지 owner가 정해야 한다.
- **P-002·P-003 Q1 = not-covered.** 콘텐츠 이용권 고객이 코들을 어떤 범위의 공급자로 인식하는지 보여주는 직접 발언을 확보하지 못했다. 확보한 것은 전부 구매 조합과 예산 배분 기록이다.
- **P-004 Q1·Q2·Q5·Q8 = not-covered.** AIDT는 출판사가 고객 접점을 보유하므로 학교 측 인식·계기·승인 근거가 코들 기록에 남지 않는다 `[source: S-042 / E-045]`. 이는 조사 실패가 아니라 구조적 결과다.
- **P-005 Q4 = single-source.** 예산 사업명이 명시된 캠프 event는 천안중 1건뿐이다 `[source: S-001 / E-001]`. 나머지는 내부 가격·원가 논의다.
- **P-005·P-006 Q7 = not-applicable.** 프로그램 상품에는 Pro 필수 관계도, 출판사 판매 구조도 적용되지 않는다.

## 4. 이번 조사가 확인한 것과 확인하지 못한 것

### 확인한 것

1. 여섯 상품 중 다섯은 코들 문의 폼 하나로 이미 다중 선택 인입되고 있다 `[source: S-019 / E-024]`
2. Pro 필수 콘텐츠 관계는 정본과 실제 판매 정책이 일치한다 `[source: S-010 / E-013]`
3. AIDT는 대금이 출판사에서 코들로 들어오며 정본 CR-011과 일치한다 `[source: S-040 / E-043]`
4. 잔여 예산으로 인접 상품을 사는 행동이 실제로 존재한다 `[source: S-025 / E-031]` `[source: S-020 / E-025]`
5. 학교 단위 반대는 상품이 아니라 지출 항목 규정에서 나온다 `[source: S-006 / E-008]`
6. 상품 발견이 상담 중 우발적으로 일어난 사례가 있다 `[source: S-054 / E-061]`

### 확인하지 못한 것

1. 교감·교장의 직접 발언. 결재선 모델은 내부 해석에 머문다
2. 라이선스 갱신·확대·이탈의 실제 결정 근거
3. 오리지널 콘텐츠 이용권 고객이 요구한 정보(목록·갱신·수업 활용)
4. AIDT의 출판사별 공식 상품명·구매 URL·체험 경로
5. 캠프와 해커톤의 학교형·교육청형 공식 패키지 정의
6. 공개 가능한 가격·성과·기관명·자산 사용권

## 7. Owner에게 5분 안에 물어볼 최소 확인 질문 (10개)

1. 허브 최상위 카드 label을 정본 6개 명칭으로 고정해도 되는가. 아니면 현행 가격 페이지 어휘(`코들 구독`, `콘텐츠 이용권`)를 따라야 하는가.
2. 공개 화면에 Pro 22,000원을 표기해도 되는가. 실제 발행 단가가 10,000~13,000원인 상황에서 정가 노출이 문제가 되지 않는가.
3. 오리지널 이용권과 씨마스 이용권을 한 학교가 동시에 구매하는 것이 현재 판매 가능한가. 문의 폼에서도 중복 선택이 가능한가.
4. `코들 Pro 콘텐츠`는 Pro 라이선스에 기본 포함되는가, 아니면 별도 이용권인가. 허브에서 무엇을 전시할 것인가.
5. 씨마스 총판 위탁판매(2026-09 개시 예정)와 허브의 씨마스 문의 CTA가 충돌하는가. 총판 계약상 코들이 직접 받을 수 없는 문의 유형이 있는가.
6. AIDT 카드에 출판사 안내 링크를 걸 수 있는가. 출판사별 공식 상품명과 학교용 안내 URL을 언제까지 받을 수 있는가.
7. AIDT의 2027학년도 이후 제공 여부를 허브에서 어떻게 표현해야 하는가. 상시 상품으로 써도 되는가.
8. AI 집중캠프와 바이브코딩 해커톤의 학교형·교육청형 구분이 실제로 존재하는가. 아니면 규모별(학급형·학년형·전교형)이 실제 축인가.
9. 천안중·광주동신여중·전북교육청 사례를 기관명 없이 익명 사례로라도 허브에 쓸 수 있는가. 사진·수치는 어디까지 가능한가.
10. 해커톤 문의와 라이선스 문의를 하나의 진입점으로 합쳐도 내부 처리가 가능한가. 현재 견적 담당이 분리돼 있는데 통합 대응이 가능한가.
