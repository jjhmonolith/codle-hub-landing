# 공개 원문·짓다 소스·AIDT 교육자료 명칭 검증 결과

기준일: 2026-08-26

## 결론

- 코들 콘텐츠의 공개 구조는 `교과별 콘텐츠 / AI 융합 콘텐츠 / 프로젝트 기반 콘텐츠`다.
- 씨마스 공개 페이지는 `인공지능 기초 교과서 완벽 대비`, `AI 기초부터 코딩 실습까지`를 전면 메시지로 사용한다.
- 짓다 공개·소스는 단순 플랫폼 소개보다 `대상별 위탁 운영 + 결과물 완성`을 중심으로 구성되어 있다.
- Owner 정정에 따른 정식명칭은 **`AIDT 교육자료`**, 풀어쓴 표기는 **`AI 디지털 교육자료`**다.
- `exhibition.codle.io`의 `AI∙디지털 교육자료`는 해당 웹전시의 관찰 표기로 보존하며 정식명칭을 대체하지 않는다.

## 짓다에서 구조 참고가 가능한 항목

- 대상별 진입: 학교 / 교육청 / 대학 / 기업
- 구매자가 얻는 결과: 작동하는 웹앱 + 기획서 + 원페이저 + 발표자료
- 운영 범위: 사전 설계, 교육, 현장 운영, 제출·갤러리, 평가 지원, 산출물 정리
- 플랫폼 기능보다 `기관이 덜 해야 하는 일`과 `참가자가 가져가는 결과`로 설명하는 방식
- CTA 종류: 상세 보기 / 운영 사례 / 문의하기 / 참가 앱 입장

위 항목은 짓다 원문의 구조·표현 관찰이다. 허브에 사실 주장으로 사용할 때는 Claim Ledger 승인 범위와 대조한다.

## 반입 금지·보류

- 짓다 소스의 공개 가격 숫자와 할인·조건
- `800개+`, `전원`, `대부분`, `3시간 내 회신` 등 미승인 수치·절대 표현
- 심사위원·시상·유명 교수·보도자료가 항상 포함된다는 표현
- `AI∙디지털 교육자료`를 허브의 정식 상품명으로 사용
- `AI 디지털교과서`를 현재 상품명으로 사용
- 출판사별 최신 구매 URL을 확인하지 않고 임의 생성
