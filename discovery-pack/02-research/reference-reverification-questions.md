# 기존 Source Pack에서 파생한 재검증 질문

- 분류: reference only
- 작성일: 2026-08-21
- 규칙: 기존 Pack의 답·상품 수·카피·구조를 이 문서로 복사하지 않는다. 질문만 새 1차 원천에 다시 묻는다.

## A. 상품 범위

1. 현재 실제로 신규 판매 가능한 제공물은 무엇인가?
2. 플랫폼, 기본 플랜, 콘텐츠 이용권, 단기 프로그램, 제휴 상품의 관계는 무엇인가?
3. 독립 구매, 애드온, 번들, 위성 랜딩 전용 상품을 어떻게 구분하는가?
4. 상품마다 공식명, 대외 노출명, 계약서 명칭이 같은가?
5. 판매 중단·예정·파일럿 상태의 제공물이 섞여 있는가?

## B. 가격과 계약

1. 가격 단위는 학생/교사/학교/학급/학기/연간 중 무엇인가?
2. 부가세, 최소 수량, 기본 플랜 포함 여부, 할인 조건은 무엇인가?
3. 공개 가능한 가격과 견적에서만 제공 가능한 가격을 누가 승인하는가?
4. 파트너 상품의 가격·명칭·콘텐츠 설명 사용 권리는 현재 유효한가?

## C. 방문자와 구매그룹

1. 실제 랜딩 방문자 중 교사·관리자·기관 담당자의 비중은 무엇인가?
2. 최초 제안자, 영향자, 승인자, 행정/구매 담당자, 실제 운영자는 누구인가?
3. 무료 시작 방문과 기관 도입 검토 방문을 어떻게 구분할 수 있는가?
4. 도입이 중단된 가장 흔한 내부 반론은 무엇인가?

## D. 내부 승인 근거

1. 결재 전에 필요한 가격표, 제안서, 보안, 개인정보, 운영 일정, 연수, 사례 자료는 무엇인가?
2. 현재 수치·수상·인증·사례의 원본 증빙, 기준일, 모수, 사용 허가는 어디에 있는가?
3. 내부 챔피언이 그대로 공유할 수 있는 1쪽 자료는 무엇이어야 하는가?

## E. 전환·측정

1. 현재 CTA별 실제 목적은 무료 사용, 자료 요청, 상품 문의, 기관 상담 중 무엇인가?
2. `form_start → API success → CRM lead → valid lead → meeting → opportunity`가 연결되는가?
3. 동일 텍스트 CTA가 위치별로 구분되어 측정되는가?
4. UTM과 서버 발급 비식별 lead ID가 보존되는가?
5. 현재 구현된 GTM/GA4 이벤트와 CRM 정본 간 차이는 무엇인가?

## F. 자산과 권리

1. 로고, 학교명, 교사 인용, 학생 사진, 수업 화면, 파트너 자산의 사용 범위와 만료일은 무엇인가?
2. 생성형 이미지와 실제 현장 사진을 어디에서 구분해야 하는가?
3. 외부 수상·인증 로고의 정확한 표기 규정은 무엇인가?

## 완료 방식

각 질문은 새 인터뷰, 운영 데이터, 계약/가격 원천, 인증서, 권리 문서 중 하나 이상의 receipt에 연결해야 한다. 답을 얻지 못한 항목은 `pending`으로 남기고 화면에 넣지 않는다.
